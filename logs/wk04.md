## Something new I picked up

CSS so far, in my words:

- Every element is a box: content, padding, border, margin.
- `display: flex` is one direction (nav bars). `display: grid` is rows and columns (cards).
- `@media` is how the same HTML becomes a phone layout. No viewport tag = phone pretends you're on a tiny desktop.
- Inspect → Styles panel. Line through a rule means it lost. `:hov` fakes hover.
- `nav a` means links inside nav. Space = inside. Comma = also.
- A class beats a tag. Same selector twice, later one wins.
- `PRD.md` is the spec the agent builds from. `AGENTS.md` is the five rules so it doesn't sneak React into a three-page site.

Still don't fully get Grid `minmax` / `1fr` without looking it up. Flexbox Froggy helped more than reading slides.

## Working with AI this week

Blackbox got me way more interested in agent tools because the problem feels real once an agent can actually do stuff for you. While I was sick I started trying things like Instinct and Muse and paying more attention to what they could access and what happened after I gave a prompt.

The main habit I picked up was planning before code. If I only say "make it look good," I get a generic AI site. Giving the agent a PRD, a sketch, and actual design rules made the result feel much more like the product Yash described. I still had to check the output. One draft called fake demo data a "Live receipt stream," so I changed it because it was not actually live.
