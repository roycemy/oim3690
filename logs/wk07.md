# Week 07

Week: 10/12 to 10/18

## What I worked on

Tuesday 10/13 was Fall Break, so there was no class. Thursday 10/15 was arrays and loops, plus debugging JavaScript. The exercise was the Member Discount: a cart total, a member checkbox, and a `getDiscount(total, isMember)` function.

I built `discount.html`. The rule is 20 if the total is 100 or more and the person is a member, 10 if only one of those is true, and 0 otherwise.

## What gave me trouble

The rule has three outcomes but only two conditions. `&&` is for "both" and `||` is for "at least one", so the order of the checks matters. If `||` goes first, a member with 150 gets 10 instead of 20. The number input also gives a string, so it needs `Number()` before comparing it to 100.

## Something new I picked up

A function that takes values in and returns a value out is easy to test without the page. I tried 150 and 50, each with and without the checkbox, and checked all four against the rule.

## Working with AI this week

The page was supposed to leave `getDiscount` for me to write. I wrote it, then had the agent check it against the rule instead of the other way around.
