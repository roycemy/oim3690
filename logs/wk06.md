## Something new I picked up

Tasks are not in `todo.html`. They're in local storage as JSON. Close VS Code, they're still there. Open the same page in another browser and it's empty.

`const` is not optional. The page can keep working without it because the name becomes a global, which is worse.

A script tag goes at the bottom of `body` so the HTML already exists. Put it in `head` and `querySelector('#todo-form')` is `null`.
