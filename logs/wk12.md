# Week 12

Week: 11/16 to 11/22

## What I worked on

AI Firewall started as Dato, a concept I'd been working on for a few weeks. For Mini Project 2 I copied it into a new repo and renamed it. It is a local-first tool that checks prompts and files before they reach ChatGPT, Claude or Gemini, finds confidential data like passwords, API keys and SSNs, and applies a policy: allow, warn, redact or block. Everything runs in the browser. Live: https://roycemy.github.io/ai-data-leak-firewall/

I owned MP2 start to finish. I wrote the planning docs first (PROPOSAL, PRD, DESIGN, AGENTS), then the detection engine, the Firewall and Policies tabs, an audit log with filters and JSON export, and a Chrome extension. I first pictured only an extension, then realized business owners need a dashboard, so I added one. I checked the engine (commit 86e3ffa) on a test string with a fake AWS key, SSN, card and email.

For Mini Project 3 I built on it instead of starting over (MP2 is saved at the tag `mp2-final`). The API is Have I Been Pwned's Pwned Passwords range endpoint. The browser hashes the password with SHA-1 and sends only the first 5 characters. The code uses `fetch` with `await` inside `try/catch` and a `response.ok` check, and it saves only counts. A breached password becomes a Critical finding, with its own audit log column and a "Password alerts" card on the dashboard. After two design reviews I made the Dashboard the home screen, renamed every visible "Dato", and rebuilt the extension. 80 unit tests and all browser checks pass.
