## What I learned from reading the AI-generated hello.html and index.html

`hello.html` is short, so it was easier to compare with `index.html`.

- Both start with `<!DOCTYPE html>`. That is not visible on the page. It tells the browser to treat the file as modern HTML.
- `<head>` is setup. The visible page is in `<body>`. `hello.html` made that obvious because the head only has a title, and the body only has a heading, a sentence, and a link back to `index.html`.
- Links use two parts: the URL lives in `href`, and the clickable words sit between `<a>` and `</a>`. In `hello.html` that is `href="index.html"`. In `index.html` the GitHub URL is in `href` too.
- `index.html` has extra tags I would have skipped: `charset="UTF-8"` and the viewport `meta` tag. Those are for character encoding and phones, not for the paragraph I wrote.
- `<img>` and `<meta>` do not wrap text, so they do not need a closing tag the way `<p>` and `<ul>` do. I learned that after staring at the image line and wondering where `</img>` was.

The other thing that clicked: AI can generate a working page, but I still have to read it. If I cannot explain `src`, `alt`, and `href`, I do not actually own the page yet.
