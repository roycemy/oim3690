## Something new I picked up

A website is a folder of files that a server hands over when you ask. For this course the server is GitHub. `index.html` is what you get if there is no extra path in the URL. DevTools Network showed that a real site like babson.edu loads way more files than I expected, and an ad blocker changes the count.

## Working with AI this week

The useful question from Tuesday was not "chatbot vs agent" as a slogan. It was how far a tool will go on its own before it comes back to you. I still treated AI like a chatbot this week: I asked for a page and stopped. I did not yet make it loop, read an error, and try again.
