# Week 08

Week: 10/19 to 10/25

## What I worked on

Tuesday 10/20 was arrays and loops again, plus debugging my MP2 code. Thursday 10/22 was the MP2 showcase. My project is Dato, a tool that scans text for confidential data before you paste it into an AI tool. It is at https://roycemy.github.io/ai-data-leak-firewall/.

I built `playlist.html` and `js/playlist.js`: an array of five songs and a `for...of` loop that adds each one to a list as an `<li>`. I added an input and an Add song button that pushes a new title onto the array and onto the page.

## What gave me trouble

The loop only runs once, when the page loads. A song added later is not in the loop, so the click handler has to add it to the page itself. I put the "create an `<li>` and append it" step in one function so the loop and the button share it.

## Something new I picked up

Name the loop variable as the singular of the array: `for (const song of songs)`. It reads like English and makes it harder to mix up the array and one item.
