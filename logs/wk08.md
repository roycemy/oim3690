# Week 08

Week: 10/19 to 10/25

## What I worked on

Tuesday 10/20 was arrays and loops again, plus debugging my MP2 code. Thursday 10/22 was the MP2 showcase. My project is Dato, a tool that scans text for confidential data before you paste it into an AI tool. It is at https://roycemy.github.io/ai-data-leak-firewall/.

I built `playlist.html` and `js/playlist.js`: an array of five songs and a `for...of` loop that adds each one to a list as an `<li>`. I added an input and an Add song button that pushes a new title onto the array and onto the page.

## Mini Project 2: the Dato build

Dato started as a concept I'd been working on for a few weeks, and I copied it into a new repo for MP2. It is local-first: it inspects prompts and files before they reach ChatGPT, Claude or Gemini, finds confidential data (passwords, API keys, SSNs, card numbers, code, contracts), and applies a policy: allow, warn, redact or block. Everything runs in the browser.

I owned this one start to finish. I wrote the planning docs first (PROPOSAL, PRD, DESIGN, AGENTS), then the detection and redaction engine, a Firewall tab with a simulated Send, a Policies tab, and an audit log with filters and JSON export. I also added inline error messages instead of pop-ups, a Reset everything button, a keyboard shortcut, empty states and phone fixes. I first pictured only a Chrome extension, then realized business owners need a real dashboard, so I added one next to the extension. I checked the engine (commit 86e3ffa) on a test string with a fake AWS key, SSN, test card and email.

## What gave me trouble

The loop only runs once, when the page loads. A song added later is not in the loop, so the click handler has to add it to the page itself. I put the "create an `<li>` and append it" step in one function so the loop and the button share it.

## Something new I picked up

Name the loop variable as the singular of the array: `for (const song of songs)`. It reads like English and makes it harder to mix up the array and one item.
