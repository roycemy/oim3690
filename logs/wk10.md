## Mini Project 3: building on AI Firewall

I thought Dato was a really good idea, so I built on it instead of starting over. MP2 is saved at the tag `mp2-final`, and I renamed every visible "Dato" to AI Firewall. Live site: https://roycemy.github.io/ai-data-leak-firewall/

The API requirement is a breach check using Have I Been Pwned's Pwned Passwords range API. The browser hashes the password with SHA-1 and sends only the first 5 characters. The code uses `fetch` with `await` inside `try/catch` and a `response.ok` check, and it saves only counts. It handles every state: off, nothing to check, loading, error (offline, 404, 429, 503) and edits made mid-check. A password found in breaches becomes a Critical finding, gets its own audit log column and filter, and shows up as "Password alerts" on the dashboard.

After two design reviews I redesigned the UI. The Dashboard is now the home screen (status line, stats, trend chart, data types, recent activity), with one clear signal per problem, plain wording, masked passwords and phone-friendly layouts. I rebuilt the extension and merged everything to the live site. 80 unit tests and all browser checks pass.
