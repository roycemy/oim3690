What gave me trouble

Also .gitignore does nothing if you already committed the file, which I did not know. I still mess up save vs commit vs push. I'll think I shipped something and it's just sitting on my laptop.

Something new I picked up

I actually sat with the AI index.html and hello.html instead of just refreshing the preview.

  • <!DOCTYPE html> doesn't show up on the page. It's just telling the browser this is modern HTML.
  • <head> is backstage. <body> is what people see.
  • charset="UTF-8" is why text doesn't turn into random garbage. Would've never guessed that.
  • The viewport meta thing is for phones. Without it, your phone pretends the site is a tiny desktop and zooms it out. That's why a lot of vibe coded pages look cooked on mobile.
  • href = where the link goes. src = where the image is. The words you actually click are between the <a> tags.
  • <img> and <meta> don't get a closing tag. <ul> is the list, <li> is one bullet.
  • <nav>, <section>, <footer> are just labeled boxes. I swapped the fake interests for mine so it didn't still say whatever the agent made up.

Working with AI this week

The Tuesday assignment was basically "stop vibe coding for a second." Find the line you don't understand and ask about that line, not "make it nicer." I did that instead of restyling it five times. Thursday we had to add tags I hadn't seen, then change one thing myself so I wasn't just accepting the dump. The first index.html it gave me worked. That's the trap. Working is not the same as I could explain it on a walkthrough.

WK039/15–9/20

Week 3

logs/wk03.md

What I worked on

Tuesday we finished HTML (tags with no closing tag, meta tags, semantic tags) and wrote the first CSS inside about-me.html. I copied the idea from class: heading, paragraph, list, a local image plus a URL image, header / main / footer. Then Thursday was selectors, cascade, and moving the CSS out of a <style> block into css/styles.css so every page can share it. Lightning talks were AI trained on AI text and NVIDIA buying Hugging Face.

What gave me trouble

The browser just ignores a CSS typo. No error, nothing. If I misspell background-color the page stays ugly and I think the file didn't save. Also relative paths again: once CSS lives in css/styles.css, the <link href> has to match that folder or the whole site goes unstyled. I did that once.

Something new I picked up

Semantic tags are just named boxes. <header>, <nav>, <main>, <section>, <footer> instead of a pile of divs. alt is for when the image dies / screen readers. title is the hover tooltip. Colors can be a name, rgb(), or hex — #006644 is Babson green. On a dark page that hex disappears as text, so I kept it on the highlight border and used a lighter green for the word Babson. Class selectors (.highlight) style a group of things. ID (#academics) is for jumping to a section. When two rules fight, more specific wins, then whoever is written later.

Working with AI this week

I had it generate about-me.html then I actually read it before committing, which is the whole point of this class and still feels slower than vibe coding. Asked it to use semantic tags on purpose so it wouldn't nest ten divs. When I said "use css/styles.css" it still tried to invent style.css in a random folder. File name has to be exact or GitHub Pages 404s the CSS.

logs/wk04.md

What gave me trouble

Phone cannot open localhost. CSS that looks fine on my laptop can fall apart at 390px until you actually hit the device toolbar.

Something new I picked up

Every element is a box: content, padding, border, margin. display: flex is one direction (nav bars). display: grid is rows and columns. @media is how the same HTML becomes a phone layout. No viewport tag = phone pretends you're on a tiny desktop. Inspect → Styles panel. Line through a rule means it lost. A class beats a tag. Same selector twice, later one wins. PRD.md is the spec the agent builds from. AGENTS.md is the five rules so it doesn't sneak React into a three-page site. Still don't fully get Grid minmax / 1fr without looking it up. Flexbox Froggy helped more than reading slides.

Working with AI this week

The 9/22 habit: write the plan before any code, hand the agent that plan. If I just say "make it look good" I get the generic AI site. If I give it PRD.md it has something to fail against. Also start a new chat when the job changes. Interview then "now build it" in the same thread brings back stuff you already said no to.
